# homebrew-aimux

Homebrew tap for [aimux](https://github.com/TraderSamwise/aimux) — a native CLI agent multiplexer for AI coding tools.

## Install

```bash
brew tap TraderSamwise/aimux
brew install aimux
```

Requires `node` and `tmux`, which brew will install as dependencies.

## Updates

The formula is auto-bumped on every aimux release by a GitHub Action in the upstream repo. To get the latest:

```bash
brew update
brew upgrade aimux
```
